# Tests et sécurité applicative (Membre 3)

## Objectif
Tester OWASP Juice Shop en fonctionnement (DAST) avec Postman, OWASP ZAP et un troisième scanner.

## Outils
- Postman / Newman : tests des API REST
- OWASP ZAP : détection des vulnérabilités web
- Nuclei (en attente de confirmation du professeur pour MScan)

## Structure
- postman/ : collection et environnement
- zap/ : configuration et scripts ZAP
- nuclei/ : templates et configuration
- reports/ : rapports générés
- scripts/ : scripts d'exécution pour Jenkins

## Statut
En cours : mise en place de l'environnement.
